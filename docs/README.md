# PocketDev documentation

The numbered sprint documents in this directory are historical planning records from the initial PocketDev implementation. They are complete and are kept for design/context archaeology; they are not the current roadmap.

Current repository/product guidance lives in:

- `../README.md` — current product overview, build/install instructions and security summary.
- `../AGENTS.md` — current architecture and maintenance guidance for repository work.

Operational notes:

- `apk-signing.md` — APK signing notes.
- `git-key-agent.md` — persistent remote Git SSH-agent behavior.
- `user-testing-apk-installer.md` — APK installer validation notes.

Historical delivery plans:

- `SPRINT_02.md`
- `SPRINT_03.md`

- `SPRINT_05.md`
